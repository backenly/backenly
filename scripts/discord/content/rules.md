# Rules

This is a small server for people building backends with coding agents. The rules are short because the bar is just "behave like a professional".

**1. Be decent.**
Disagree with the idea, not the person. We follow the [Contributor Covenant](https://github.com/backenly/backenly/blob/main/CODE_OF_CONDUCT.md), and it applies here exactly as it applies in the repo.

**2. Never post a secret.**
No `.env` files, connection strings, API keys, setup tokens, or JWTs. Not in a screenshot either. If you paste one by accident, tell a moderator and rotate it immediately — assume it is public the second it lands.

**3. Security issues are not public.**
Email **support@backenly.com** with `SECURITY` in the subject. A public report is a working exploit handed to everyone running this software before any of them can patch it. You get an acknowledgement in 72 hours. See [SECURITY.md](https://github.com/backenly/backenly/blob/main/SECURITY.md).

**4. Use the right channel.**
Support questions go in the help forums, one post per problem, not in chat. Chat is for talking; forums are searchable and stay useful to the next person.

<!-- split -->

**5. Ask well.**
Say what you did, what happened, and what you expected. Paste the actual error, not your description of it. "It doesn't work" costs everyone a round trip.

**6. No spam, no self-promotion that isn't a project.**
Showing what you built in showcase is the point of the server. Dropping a link to an unrelated product, a paid service, or an invite to another Discord is not. No DM advertising to members — that is an instant ban.

**7. No agent-generated noise.**
Posting an unreviewed wall of model output as if it were an answer wastes the time of everyone who reads it. If an agent wrote it, read it first and say so.

**8. English in the main channels.**
Only so moderation can actually moderate. No judgement on anyone's English.

## Enforcement

Warning, then timeout, then ban. Secrets posted at scale, harassment, and DM spam skip straight to the ban. Moderation actions and the reasoning are logged internally, and you can always ask a moderator why.

-# Questions about the rules go to any @Moderator or @Core Team member.
