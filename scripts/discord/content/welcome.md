# Welcome to Backenly

**Your coding agent builds it. Backenly keeps it running.**

Backenly is an autonomous backend platform for agentic coding: PostgreSQL, REST APIs, auth, storage, realtime, and functions, driven by the coding agent you already use over MCP, with every change planned, verified, and reversible.

This server is where the people running it compare notes.

## There are two ways to run Backenly, and this server has a door for each

☁️ **Backenly Cloud** — the managed platform at [backenly.com](https://backenly.com). You create a project, point your agent at it, and never think about Postgres, PostgREST, or uptime.

🧱 **Self-Hosted** — the same platform, Apache-2.0, on your own infrastructure. `npm run selfhost` and you own the whole stack. One deployment is one project.

Onboarding asked you which one you use. Whichever you picked unlocked a category with its own start-here, help forums, and changelog. **Pick both if you use both** — plenty of people prototype on Cloud and ship self-hosted, or the other way round. You can change your answer any time under **Channels & Roles**.
