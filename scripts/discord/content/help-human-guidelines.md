# Read this before posting

Questions that aren't about a specific agent run: projects, dashboard, auth, storage, realtime, functions, keys, limits, installs, upgrades, operations. **One post per question.**

## What a good post contains

**A title that is the question.** "RLS policy blocks the owner's own rows" beats "help please". People scroll titles.

**What you did, what happened, what you expected.** In that order.

**The actual error.** In a code block, not paraphrased, not cropped to the last line. Include the request id if you have one.

**Your setup.** Cloud or self-hosted. If self-hosted: version, OS, Node version, and whether you're on the bundled Compose stack or your own PostgreSQL and PostgREST.

**What you already tried.** Saves everyone a round trip.

## Redact

No `.env` contents, connection strings, API keys, setup tokens, or JWTs — screenshots included. If one slips through, say so and rotate it.

## Tags

`Open` when you post, **`Answered` when it's resolved**, with a reply saying what the fix was. `Needs info` means we're waiting on you.

## This isn't a ticket queue

It's a small team and a public forum. Other members answer faster than we do, and often better. If your question needs an account, an invoice, or anything private, email **support@backenly.com** instead.

-# Security issues never go here. Email support@backenly.com with SECURITY in the subject.
